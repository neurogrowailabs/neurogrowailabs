## 🚀 Qué incluye esta plataforma

- **Web interactiva:** Presentación de servicios, portafolio y filosofía del laboratorio.
- **Diagnóstico de Arquitectura con IA:** Módulo interactivo en vivo (`/api/diagnostico`) que analiza el requerimiento del cliente y genera una propuesta técnica con estimación para WhatsApp.
- **Ecosistema Labs:**
  - **MiVeci:** Aplicación web progresiva (PWA) de comercio hiperlocal con geolocalización y visión computacional.
  - **Data Lab:** Consultoría en diseño experimental (DoE) y modelado estadístico en RStudio.
- **Cumplimiento legal (Ecuador):** Adaptada a la Ley Orgánica de Protección de Datos Personales (LOPDP), acuerdos de confidencialidad (NDA) y contratos de servicio (MSA).

---

## 🛠️ Tecnologías utilizadas

- **Backend:** Laravel 12 / PHP 8.4
- **Frontend:** Blade, Tailwind CSS y animaciones con GSAP
- **Infraestructura:** Contenedor Docker desplegado en Render con CDN Cloudflare
- **Base de datos:** SQLite para registro inmutable de consentimientos y diagnósticos

## 💻 Desarrollo local

```bash
# 1. Clonar el repositorio
git clone https://github.com/neurogrowailabs/neurogrowailabs.git
cd neurogrowailabs

# 2. Instalar dependencias
composer install
npm install

# 3. Iniciar servidor local
php artisan serve --port=8002
```
